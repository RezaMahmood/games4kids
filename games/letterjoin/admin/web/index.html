          Settings

          Daily practice time

          Every child gets the same daily practice time. Their clock starts with their first pen stroke of the day, counts down while they use the app, pauses after 30 seconds without a touch, and tells them when they are done. It starts again at midnight on each child's own device. Set 0 to turn it off.

          Hard mode asks the child to write a word, sentence or passage themselves with no outline. This is where each device starts. A child can still turn it on or off for themselves, and that choice sticks on their device.
